# Keyboard shortcuts and controls

Press `?` in the app for this list. Single-key shortcuts work while no text
field has focus.

## Files and workspaces

| Keys | Action |
| --- | --- |
| Ctrl+O | Open a file |
| Ctrl+Shift+O | Open a workspace |
| Ctrl+N | New workspace |
| Ctrl+I | Import an export `.json` |
| Ctrl+D | Download pending |
| Ctrl+E | Export for Blender (`.glb`) |
| Ctrl+Shift+E | Export as OBJ |
| Ctrl+, | Roblox access |

## Panels and view

| Keys | Action |
| --- | --- |
| Ctrl+B | Show or hide the library |
| Ctrl+Shift+B | Show or hide the inspector |
| F | Frame the model |
| Space | Play or pause the animation |
| 1 / 2 / 3 | Solid / solid and wireframe / wireframe |
| M | Maps on or off |
| G | Ground grid on or off |
| K / J | Skeleton / joints of an animated model on or off |
| L | Next lighting preset |
| F12 | Save the view as an image |
| ? | Show the shortcuts |

## Library

| Keys | Action |
| --- | --- |
| Ctrl-click | Add a model to the selection, or take it out |
| Shift-click | Select a range |
| Ctrl+A | Select every model shown (pointer over the library) |
| Esc | Clear the selection (pointer over the library) |

## Viewport

| Mouse | Action |
| --- | --- |
| Left-drag | Orbit |
| Right- or middle-drag | Pan |
| Scroll | Zoom |
| Double-click | Frame the model |
